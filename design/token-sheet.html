The marks are the owner's files, unmodified, on the art's own white (--color-mark-tile). In the header, the tile only shows in dark mode. The hero card is light in both modes. Brand teal, coral, and butter are fixed and used only on that white.

Color

Each token has a light and a dark value, written light-dark(light, dark).

Contrast (computed live, WCAG 2.2 AA)

Text needs 4.5:1. Input edges, focus rings, and the crown need 3:1. Disabled text is exempt.

Type

The system font stack, with no font files. Headings get their character from weight (heavy, slightly tight), not a second family.
