Figma mapping

tokens.css is the source of truth. Figma mirrors it with matching names: drop the -- and turn the first hyphen into a slash, so --color-accent ↔ color/accent and --type-heading-1 ↔ type/heading-1.

Colors are color variables with Light and Dark modes. Sizes, spacing, radius, lines, weights, and breakpoints are number variables. The two fluid sizes get Phone (390) and Desktop (1280) modes. Type roles are text styles and shadows are effect styles. Easing and layers have no Figma equivalent and aren't mirrored. On Figma Pro the sync is manual: push changes from this sheet, then check for drift at each milestone.

Color

Each token has a light and a dark value, written light-dark(light, dark); check:tokens fails any that doesn't.

Contrast (computed live, WCAG 2.2 AA)

Text needs 4.5:1. Input edges, focus rings, and the crown need 3:1. Disabled text is exempt.

Type roles

Components set type with a role (font: var(--type-body)), never a scale step; check:tokens enforces it. Display and amount use fluid sizes that shrink on phones.
