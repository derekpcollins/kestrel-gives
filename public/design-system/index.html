Stage A

Buttons

One button per action. Primary for the main action on a screen (one per view), secondary for alternatives, quiet for low-emphasis actions, danger for destructive ones. Disabled uses aria-disabled so the button stays focusable; loading adds aria-busy and a spinner that stops under reduced motion. Hover, pressed and focus are forced here with documentation-only classes.

Links go somewhere; buttons do something. Links are always underlined, so they don't rely on color. External links open in a new tab, show the external icon and say so to screen readers.

Banners

A message about the whole page or event that stays until the situation changes. Phase (butter) says where the event is and is a status region; info gives neutral context; success, warning and danger report outcomes. Errors put focus or a link at the field that needs fixing.
