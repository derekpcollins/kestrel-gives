Stage A

Buttons

One button per action. Primary for the main action on a screen (one per view), secondary for alternatives, quiet for low-emphasis actions, danger for destructive ones. Disabled uses aria-disabled so the button stays focusable; loading adds aria-busy and a spinner that stops under reduced motion. Hover, pressed and focus are forced here with documentation-only classes.

      Stage C2

      Dialogs

      Native modal dialogs: focus moves in and stays in, the page behind goes inert, Escape closes (except while a request runs) and focus returns to the button that opened it. Confirm shows what you're agreeing to, with amounts computed from the data. Danger starts on the safe button. Type-to-confirm keeps its button inactive until the event name is typed exactly. Info (the welcome) offers a way on instead of asking: its dismiss is the primary and takes first focus, and the tour is a real link. When it's taller than the screen only its body scrolls, with a divider above the actions. On phones the actions fill the row, and each takes the full width when they wrap.
